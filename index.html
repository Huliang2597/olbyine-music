音乐来源

在线账号和服务器在“流媒体”页里切换，本地和网盘里的歌进音乐库，它们共用同一个播放队列。

本地音乐库

按文件夹扫描，专辑有网格、Cover Flow 和球形三种视图，支持 FLAC、ALAC、WAV、AIFF。

网易云音乐

我的音乐、排行榜、搜索、私信、评论、MV 和播客，听歌记录会同步回账号。

SoundCloud

发现与搜索；登录后可以喜欢、转发、关注、发私信和加入歌单。

Navidrome

连接自建的 Navidrome 或 Subsonic 兼容服务器，浏览专辑、艺人、歌单和收藏。

WebDAV 与 NAS

Alist、群晖、Nextcloud、坚果云里的音乐，可以在线播放，也可以导入音乐库。

歌词

自动从多个歌词库匹配，翻译和罗马音可以单独开关。

逐字歌词

唱到哪个字亮哪个字。双击一行跳到这一句。

翻译罗马音TTML / LRC / QRC

MV 歌词

全屏大字号，逐字出现，横屏竖屏自动排版。

跃动倾斜排版

应用外显示

桌面悬浮歌词可拖动、缩放、控制播放；状态栏、锁屏和小组件也能显示。

悬浮窗状态栏小组件

界面风格

可以选 iOS、ColorOS、澎湃 OS 或原生 Android 的样式，配色、控件形状和图标会一起切换。点下面的按钮试试。

声音

USB 独占输出

接 USB 解码器时绕过系统混音，按原采样率输出，支持位完美。

10 段均衡器

预设和手动调节，带前级增益，实时显示频响曲线。

歌曲过渡

淡入淡出和自动过渡，切歌没有空白。

安装

  1. 在 GitHub 发布页下载 olbyine-music-v1.0.apk。
  2. 打开安装包，按提示允许安装未知来源应用。
  3. 打开应用，导入本地音乐，或在“流媒体”里登录账号、连接服务器。

需要全新安装。包名是 com.olbyine.music，不会覆盖旧版 Lyra，旧版的音乐库和登录要重新导入。

可选权限：悬浮窗用于桌面歌词，通知读取用于显示其他播放器的歌词。不开也能正常播放。
