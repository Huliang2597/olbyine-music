Sources

音乐来源

在线账号和服务器在“流媒体”里切换，本地与网盘里的歌进音乐库，它们共用同一个播放队列。

本地音乐库

按文件夹扫描，专辑有网格、Cover Flow 和球形三种视图，支持 FLAC、ALAC、WAV、AIFF。

网易云音乐

我的音乐、排行榜、搜索、私信、评论、MV 与播客，听歌记录同步回账号。

洛雪音乐

搜索、推荐歌单、排行榜与我的歌单四个分页；支持导入 `.lxmc` 歌单与自定义源脚本。

LX Music自定义源

SoundCloud

发现与搜索；登录后可以喜欢、转发、关注、发私信和加入歌单。

Navidrome

连接自建的 Navidrome 或 Subsonic 兼容服务器，浏览专辑、艺人、歌单与收藏。

WebDAV 与 NAS

Alist、群晖、Nextcloud、坚果云里的音乐可以在线播放，也可以导入音乐库。

Library

音乐库

除了播放，还能把音乐整理成你想要的样子。

作曲人分类

读取音频文件里的作曲人标签，同一个人自动合并；没有标签的由网易云补全，卡片显示艺名。

ID3 / FLAC自动归类

下载管理

网易云歌曲一键下载，自动写入标签与封面，歌词保存在音频同目录，统一放在 Download/Olbyine。

进度通知内嵌封面

播放记忆

关掉应用再打开，队列、歌单和进度都还在；点定位能回到当初播放它的那个歌单。

队列持久化回到来源
Lyrics

歌词

自动从多个歌词库匹配，翻译和罗马音可以单独开关。

逐字歌词

唱到哪个字亮哪个字。双击一行跳到这一句。

翻译罗马音TTML / LRC / QRC

MV 歌词

全屏大字号，逐字出现，横屏竖屏自动排版。

跃动倾斜排版

应用外显示

桌面悬浮歌词可拖动、缩放、控制播放；状态栏、锁屏和小组件也能显示。

悬浮窗状态栏小组件
Styles

界面风格

iOS、ColorOS、澎湃 OS 或原生 Android，配色、控件形状和图标会一起切换。点下面的分段按钮试试。

Sound

声音

从解码到输出，尽量不经过多余的环节。

USB 独占输出

接 USB 解码器时绕过系统混音，按原采样率输出，支持位完美。

10 段均衡器

预设和手动调节，带前级增益，实时显示频响曲线。

歌曲过渡

淡入淡出和自动过渡，切歌没有空白。

Install

安装

  1. 在 GitHub 发布页下载 Olbyine-1.1-release.apk。
  2. 打开安装包，按提示允许安装未知来源应用。
  3. 打开应用，导入本地音乐，或在“流媒体”里登录账号、连接服务器。

全新安装。包名是 com.olbyine.music，不会覆盖旧版本，旧版的音乐库与登录信息需要重新导入。

可选权限：悬浮窗用于桌面歌词，通知读取用于显示其他播放器的歌词。不开也能正常播放。
